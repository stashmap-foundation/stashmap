# Recursive embed integration scenarios

A recursive scenario crosses at least two explicit placement boundaries: the note embeds an outer source, that source embeds another source, and the terminal source composes first. The corpus table exercises every recursive conformance family through the filesystem application on initial render and reload. The interaction table exercises real UI gestures in both untouched projected and materialized-first states, asserting persisted Markdown, source integrity, singularity, and reload where applicable.
